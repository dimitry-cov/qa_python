# qa_python
# Проект: тестирование приложения BooksCollector
В данном проекте реализовано покрытие юнит-тестами класса BooksCollector
Тест написаны с использлованием фреймворка pytest и находятся в файле tests.py

#Список реализованных тестов: 
1. test_add_new_book_different_lenghts - проверяет добавление новой книги с разной длиной названия (15 (в диапазоне), 40 (граница), 41 (превышение границы), 50 (невалидное) символов). Использована параметризация
2. test_get_book_genre_valid - проверяет корректность получения жанра для существующей книги
3. test_set_book_invalid_genre - проверяет, что книге не устанавливается жанр, которого нет в списке доступных
4. test_get_books_with_specific_genre_valid - проверяет правильный возврат методом списка книг с заданым жанром
5. test_get_books_genre_valid - проверяет возврат методом актуального словаря со всеми книгами и жанрами
6. test_get_books_for_children_empty_result - проверяет, что книги жанров не для детей не попадают в список книг для детей
7. test_add_book_in_favorites_valid - проверяет успешное добавление существующей книги в список избранного
8. test_delete_book_from_favorites_valid - проверяет успешное удаление книги из списка избранного
9. test_get_list_of_favorites_books_valid - проверяет получение списка избранных книг

Примечение: Для запусков тестов необходимо установить pytest (если не установлен) и выполнить команду в терминале из корневой папки проекта pytest tests.py (BASH)
